tandem · distributed training from scratch

in lockstep.

Designed, built and measured by Sankur KunduOpen source (Apache-2.0) · page updated 15 Oct 2026

The parallelisms behind large-model training, on PyTorch tensors and autograd but with no torch.distributed and no NCCL: its own ring all-reduce, reduce-scatter and all-gather underneath DDP, ZeRO-1, 2 and 3, and GPipe and 1F1B pipelines. On two T4 GPUs every one ends with exactly PyTorch's weights.

02 · The C++ engine

Collectives without NCCL

The collectives moved into a PyTorch C++ extension: lock-free single-producer, single-consumer rings in shared memory and a progress thread on the CPU; on GPUs, buffers shared through CUDA IPC, ordered by interprocess events and reduced by a fused CUDA kernel, so the host never waits for a piece.

03 · Parallelisms

Every way to split a model

Each parallelism is built on the same three collectives, in the order Megatron-LM and FSDP use them.

DDP, overlapped

Gradient buckets reduced as backward fills them, so communication hides behind compute.

ZeRO-1, 2 and 3

Sharded optimizer state, gradients and, FSDP-style, parameters gathered just before use and prefetched: 17% less memory per GPU than DDP.

GPipe and 1F1B

Pipeline schedules in Megatron-LM's order; 1F1B uses 32–52% less memory than GPipe on an 86M-parameter GPT.

What tandem adds

Large-model training, understood from the wire up

What torch.distributed, NCCL, DeepSpeed and Megatron do, rebuilt so that every byte on the wire is accounted for.

  1. Own collectives

    Ring all-reduce, reduce-scatter and all-gather within 2% of NCCL's bandwidth at 64–256 MB.

  2. Every parallelism

    DDP, ZeRO-1/2/3 and GPipe/1F1B, bit-identical to PyTorch after 20 steps.

  3. A C++/CUDA engine

    Shared-memory rings, CUDA IPC and a fused reduce kernel: 1.6–2.8× faster.

  4. Memory, measured

    ZeRO-3 17% less than DDP; 1F1B 32–52% less than GPipe.

Where it falls short

tandem's DDP reaches 86% of PyTorch DDP's throughput, and the C++ engine has not yet been timed against NCCL across two GPUs.
