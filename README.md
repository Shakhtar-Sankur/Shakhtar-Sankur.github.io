# Sankur Kundu — personal site

Static site. No build step, no dependencies.

**Live:** https://shakhtar-sankur.github.io/

| File | What it is |
|---|---|
| `index.html` | The whole site — work, products, timeline, contact |
| `Sankur-Kundu-Resume.pdf` | Résumé, linked from the site |
| `avatar.jpg` | Profile photo |

Hosted with GitHub Pages from the `main` branch, root folder. This is the
user-pages repository (`Shakhtar-Sankur.github.io`), so it serves from the
domain root rather than a subpath.

## Editing

Product figures on this page (language counts, defect counts, call volumes) are
copied from the products themselves. When one of those moves, it has to be
changed here by hand — nothing generates this file. The numbers as they stand
were checked against source on 5 September 2026.
